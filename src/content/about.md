I'm Rining Wu, a PhD researcher working across AI and computational neuroscience at the University of Leeds and the University of Birmingham. My doctoral research studies how neurons respond to changing visual scenes, using deep learning to model information over time.

Alongside research, I have experience building protein-modelling platforms, internal AI applications and web services. My work combines machine learning with software engineering: turning models into tools that scientists and other users can run, and deploying the systems that support them.

## Research

My co-authored work covers neural response prediction, protein solubility, industrial sensor data and medical navigation.

- **[Aligning Neuronal Coding of Dynamic Visual Scenes with Foundation Vision Models](https://doi.org/10.1007/978-3-031-73223-2_14)** — ECCV 2024. Vi-ST combines features from vision models with temporal processing to predict retinal neuronal responses to natural video. [Research overview](/publications/aligning-neuronal-coding-of-dynamic-visual-scenes-with-foundation-vision-models/) · [Code](https://github.com/wurining/Vi-ST)
- **[Improving neuronal coding of dynamic visual scenes with foundation vision models](https://sites.google.com/view/hcvworkshop2024/accepted-papers)** — Human-inspired Computer Vision Workshop, ECCV 2024. An extended abstract accepted for a poster on modelling neuronal responses to dynamic visual scenes.
- **[HybridGCN for Protein Solubility Prediction with Adaptive Weighting of Multiple Features](https://doi.org/10.1186/s13321-023-00788-8)** — Journal of Cheminformatics, 2023. Combines learned protein representations with biophysical features for solubility prediction.
- **[Enhancing Accuracy in Gas–Water Two-Phase Flow Sensor Systems Through Deep-Learning-Based Computational Framework](https://doi.org/10.1109/JSEN.2024.3475292)** — IEEE Sensors Journal, 2024. Examines deep learning for improving predictions from gas–water flow sensor data.
- **[Harnessing Multiple Time-Series Sensor Data: Evaluating the Efficacy of Various Machine Learning Models in Predicting Gas-Water Two-Phase Flow](https://doi.org/10.1615/tfec2024.ml.050649)** — 9th Thermal and Fluids Engineering Conference, 2024. Evaluates machine learning models using multiple sensor time series.
- **[A robust framework with knowledge-guided planning and fiducial-based registration for bronchoscopy navigation system](https://doi.org/10.1088/1361-6560/add8dc)** — Physics in Medicine and Biology, 2025. Studies knowledge-guided planning and fiducial-based registration for bronchoscopy navigation.
